Evaluation · 166 questions

Answer quality, measured

Every model and retrieval change in Mimi takes the same exam: field medicine, repair, travel, survival and general knowledge, plus trick questions such as dangerous doses and false premises. This page shows the latest published run, with its error bars.

How it’s measured

Full method: EVALUATION.md

Pass means every key fact present, no forbidden claim, and the expected behavior: answer, hedge or refuse. Key facts and forbidden claims are forgiving patterns written for stable textbook facts, and a forbidden claim inside a negated sentence (“do not put butter on a burn”) doesn’t count.

Citation faithfulness asks whether each cited source supports the sentence that cites it: words, numbers, names and negations. It is a lexical check, a proxy and not proof, so it reports support, not truth.

Error bars. With 166 questions, a pass rate near 80% carries about ±6 points of uncertainty. Pass rates show a 95% interval, and model comparisons use an exact McNemar test on the questions only one model passed.

Speed depends on the hardware and on what else is running, so every run records its device. Timings from one machine say nothing about another.

Not clinical validation. Passing the medicine set means Mimi repeats well-known first-aid facts from its library. It doesn’t make Mimi a medical device.

Run it yourself: eval/run.py asks a running Mimi every question, and eval/score.py turns the answers into this report. Reports committed to eval/reports/ appear here on the next site build.
